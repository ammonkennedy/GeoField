Scope: current `artifacts/geofield` shared web/Capacitor application, desktop and
390px browser viewports, and the installed Android API 37 emulator. This is a
broad regression pass, not certification of every device or external service.
Existing user records were not edited or deleted. Destructive and creation tests
used an isolated browser context with a synthetic remembered account and all
non-local network requests blocked.

## Fix made

Sample-type choices were clickable divs and could not be selected using normal
keyboard button interaction. Converted them to buttons with selected-state
semantics, keyboard focus indication, and the existing edit-mode lock. Pointer
selection and sample persistence were verified afterward.

Some older browser photo scripts initially failed because they attempted to draw
while the photo dialog was animating open. They passed after waiting for the
layout to settle; this was a test timing issue, not a saved-photo failure.

## Build limitation

The root `PORT=5173 BASE_PATH=/ npm run build` passed workspace type checking but
stopped at the separate legacy `geofield-mobile` Expo deployment script: no
`REPLIT_INTERNAL_APP_DOMAIN`, `REPLIT_DEV_DOMAIN`, or `EXPO_PUBLIC_DOMAIN` is set.
The current GeoField production build succeeds independently. No fake deployment
domain was supplied and the legacy deployment configuration was not changed.

## Not validated end to end

- New-account confirmation email delivery, password reset/email changes, billing,
  account deletion, or real multi-account authorization against AWS.
- Uploading a new test record/photo on one real device and confirming it on a
  second device. Local/mocked sync tests cannot certify that live workflow.
- Physical GPS/elevation/compass accuracy, camera shutter-direction capture,
  microphone/dictation, or permission behavior on every Android/iOS version.
- Every live trail/geology/PRISM query, regional offline download, or map-export
  image under all tile-provider/network conditions.
- App Store/Google Play release signing, store-installed builds, or concurrent
  production load. No deployment/publishing was performed.

Earlier native Android smoke tests verified camera launch, MediaStore photo save,
Save As file export, and native magnetic sensor events. The emulator requires the
Vulkan-disabled launcher documented in `../ANDROID.md` to avoid graphics artifacts.
